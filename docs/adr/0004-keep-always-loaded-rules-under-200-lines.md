# 0004. 항상 읽히는 규칙은 200줄 아래로 두고 상황별 규칙은 paths 규칙으로 나눈다

- 상태: 채택
- 날짜: 2026-11-04

## 배경

공통 규칙을 `AGENTS.md`로 합치자 279줄이 되었습니다. Claude Code 공식 문서(memory)는 항상 읽히는 파일을 200줄 아래로 두고, 일부에만 필요한 내용은 skill이나 `paths` 규칙으로 옮기라고 권합니다. 항상 읽히는 줄은 모든 세션에서 컨텍스트와 주의를 씁니다.

## 결정

- 코드를 다룰 때만 필요한 규칙은 `.claude/rules/code.md`, 문서를 쓸 때만 필요한 규칙은 `.claude/rules/writing-docs.md`로 옮깁니다. 규칙 문장은 지우지 않고 위치만 옮깁니다.
- 셸 명령으로 파일을 고칠 때는 `paths` 규칙이 자동으로 읽히지 않으므로 먼저 직접 읽도록 공통 규칙에 적습니다.
- `AGENTS.md`가 200줄을 넘으면 저장소 검사가 실패합니다.

## 검토한 대안

| 대안 | 장점 | 단점 |
|---|---|---|
| 그대로 두기 | Codex가 모든 규칙을 항상 읽음 | 권장 크기를 넘고 매 세션 비용이 큼 |
| 모델이 원래 지키는 일반 규칙을 지우기 | 가장 짧음 | 사용자가 정한 기준이 사라짐 |

## 결과

- claude-home `AGENTS.md` 196줄, 새 프로젝트 `AGENTS.md` 197줄입니다.
- Codex는 옮긴 규칙을 표의 안내를 따르는 만큼만 읽습니다.
- `--user`로 사용자 설정에도 공통 규칙을 넣으면 claude-home 기반 프로젝트에서 두 번 읽힙니다(`docs/setup.md`에 비용과 피하는 법).
