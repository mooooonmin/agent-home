# AI·ML 약어

출처: An-Illustrated-Guide-To-AI-Agents-ko/appendix/glossary.ko.md. 원본 용어집이 바뀌면 이 파일도 함께 고칩니다.

| 약어 | 원어 | 한국어 / 설명 |
|---|---|---|
| A2A | Agent2Agent | 에이전트끼리 통신하기 위한 프로토콜 |
| AST | Abstract Syntax Tree | 추상 구문 트리. 코드를 구조적으로 분석할 때 사용 |
| CoD | Chain-of-Draft | 초안의 사슬. 짧은 메모 형태로 추론해 토큰을 줄이는 기법 |
| CoT | Chain-of-Thought | 생각의 사슬. 답 전에 단계별 추론을 쓰게 하는 기법 |
| DPO | Direct Preference Optimization | 직접 선호 최적화. 보상 모델 없이 선호 데이터로 미세 튜닝 |
| DSA | DeepSeek Sparse Attention | DeepSeek의 희소 어텐션 |
| ETO | Exploration-based Trajectory Optimization | 탐색 기반 궤적 최적화. 에이전트 실행 기록으로 학습 |
| FLOPs | Floating Point Operations | 부동소수점 연산량(또는 초당 연산 수) |
| GQA | Grouped-Query Attention | 그룹 쿼리 어텐션. 여러 쿼리 헤드가 키·값을 공유 |
| GRPO | Group Relative Policy Optimization | 그룹 상대 정책 최적화. 추론 모델 강화학습에 쓰이는 방법 |
| IoA | Internet of Agents | 에이전트 인터넷. 여러 에이전트가 연결된 협업 구조 |
| LLaVA | Large Language and Vision Assistant | 대표적인 오픈 시각-언어 모델 |
| LLM | Large Language Model | 대규모 언어 모델 |
| LoRA | Low-Rank Adaptation | 저랭크 어댑테이션. 적은 파라미터만 학습하는 미세 튜닝 |
| LtM prompting | Least-to-Most Prompting | 쉬운 하위 문제부터 차례로 푸는 프롬프팅 |
| MAS | Multi-Agent System | 멀티 에이전트 시스템 |
| MCoT | Multimodal Chain-of-Thought | 멀티모달 생각의 사슬 |
| MCP | Model Context Protocol | 모델 컨텍스트 프로토콜. 도구·데이터 연결 방식의 표준 |
| MHA | Multi-Head Attention | 멀티 헤드 어텐션 |
| MLA | Multi-head Latent Attention | 멀티 헤드 잠재 어텐션. 키·값을 압축해 메모리 절약 |
| MLLM | Multimodal LLM | 멀티모달 LLM |
| MLP | Multi-Layer Perceptron | 다층 퍼셉트론 |
| MMR | Maximal Marginal Relevance | 최대 한계 관련성. 관련성과 다양성을 함께 고려한 선택 |
| MoE | Mixture of Experts | 전문가 혼합 |
| MQA | Multi-Query Attention | 멀티 쿼리 어텐션. 모든 헤드가 키·값 하나를 공유 |
| ORM | Outcome Reward Model | 결과 보상 모델. 최종 답만 평가 |
| PRM | Process Reward Model | 과정 보상 모델. 추론 단계마다 평가 |
| RAG | Retrieval-Augmented Generation | 검색 증강 생성 |
| ReAct | Reason and Act | 추론과 행동을 번갈아 하는 에이전트 루프 |
| RL | Reinforcement Learning | 강화학습 |
| RLHF | Reinforcement Learning from Human Feedback | 사람 피드백 기반 강화학습 |
| RLVR | Reinforcement Learning with Verifiable Rewards | 검증 가능한 보상을 이용한 강화학습 |
| RM | Reward Model | 보상 모델 |
| RoPE | Rotary Position Embedding | 회전 위치 임베딩 |
| SFT | Supervised Fine-Tuning | 지도 미세 튜닝 |
| TIR | Tool-Integrated Reasoning | 도구 통합 추론. 추론 중에 도구를 함께 사용 |
| ToM | Theory of Mind | 마음 이론. 타인의 의도·믿음을 추론하는 능력 |
| TTRL | Test-Time Reinforcement Learning | 테스트 시점 강화학습 |
| ViT | Vision Transformer | 비전 트랜스포머 |
| ViViT | Video Vision Transformer | 비디오 비전 트랜스포머 |
